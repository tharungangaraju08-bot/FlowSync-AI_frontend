What React Router does?

Ans: 

    It basically enables client side routing through out the application allowing user to build multi page experiences with a single page application and default react doesn't have this property so React Router fills the gap. It has 5 major functions: 1. Navigation without reloading, 2. Bookmarkable URL's(which allows back and forth as expected), 3. Declarative definition(it allows routing declaratively), 4. Nested routing, 5. Dynamic routing.

Difference between pages and components?

Ans: 

    Component: It is a small reusable block that can be used in multiple pages like a button, card, sidebar, navigation menu
    Page: It is a whole block where multiple components present

    if we consider a house app then furniture like sofa, cupboard are components and bed room, living room are pages.

Why scalable architecture matters?

Ans:

    Scalable system allows to maintain high work load or low work load accordingly. It matters most because if the website went viral then traffic will be more to the website then a non scalable architecture can't handle that much and it will crash and also at some point of time it may have low traffic then the resources need should be decreased so, scalable architecture maintains the network traffic by allowing resources accordingly and helpint the system to not crash and to reduce cost
